# CuttleX 功能性开发方向（2026-08 确认 v2）

> 已确认的开发方向。首批：**操作体验优化（多选/拖拽/二维码）**；随后：**移动端适配**、**审计日志**。

## ✅ 确认方向

### P0 操作体验优化（本批）

1. **节点库批量操作**：多选（全选/反选）、批量改备注/分组/启用停用/删除。
2. **规则链拖拽排序**：拖拽调整规则顺序；临时停用（保留配置不删除）；复制规则。
3. **节点二维码**：节点详情/行内二维码，手机扫码导入。

### P1 移动端适配

- 节点表格/编辑抽屉在窄屏下的可用性：卡片化列表、触屏操作、编辑抽屉全屏化。

### P2 审计日志

**审计范围**（CuttleX 是自托管管理工具，不承载用户流量）：

- 管理操作：登录成功/失败、订阅创建/编辑/删除/轮换 token、节点导入/编辑/删除、集合变更、远程源抓取结果。
- 订阅交付：每次 token 拉取的时间、来源 IP（脱敏）、User-Agent、近 N 次历史 → 发现订阅地址泄漏/盗用。

**不做**：用户通过代理访问了哪些网站 —— 流量不经过 CuttleX，工具层面无感知、不应感知。

**落地**：D1 新增审计表 + 管理面板"审计日志"页（类型/时间筛选、分页、保留 N 天）；服务端统一拦截记录，后续新操作自动纳入。

## ❌ 已否决 / 暂缓

- **节点测速（三网 IP）**：已评估，SOCKS/HTTP 协议节点的隧道测速对使用 SS/VLESS 的用户无意义；SS/VLESS 全协议客户端在 Worker 内实现成本过高。**不做**。若未来有 VPS 版（本地完整代理客户端），可再评估。

- **订阅差分 & 变更提醒、定时刷新失败回退、规则模板库、i18n、加密导出备份、TUN 配置导出、凭据加密存储**：暂缓，待首批功能上线后再评估。

---

## 技术备忘

- 测速已否决，不再需要 `cloudflare:sockets` 依赖。
- 审计日志渲染需脱敏（IP 只保留前两段 / 国家+城市级）。
- 仓库不含任何真实部署域名（`wrangler.json` 使用占位 `your-domain.example`，部署时通过 `wrangler deploy --var CUTTLE_PUBLIC_ORIGIN:https://实际域名` 注入）。
